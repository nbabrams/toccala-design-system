The Toccala wordmark — the only brand mark in the source file. There is no symbol/icon lockup.

```jsx
<Wordmark plate width={184} />
<Wordmark tone="green" width={140} basePath="../../" />
```

Colour it with `tone` — `cream`, `green` and `ink` are pre-tinted SVG files in `assets/marks/`. On light grounds either use `tone="green"` bare or the `plate` variant; never place the cream mark directly on cream.
