Uppercase wide-tracked eyebrow. Use above every headline block; `plan` inside cards, `dark` on the ink/green bands, `hero` for the oversized display kicker.

```jsx
<Kicker tone="label">Kicker Label Here</Kicker>
<Kicker tone="plan">Plan Name Here</Kicker>
<Kicker tone="hero">A top kicker with</Kicker>
```

Never sentence-case a kicker and never drop the letter-spacing — the wide track is the identity.
