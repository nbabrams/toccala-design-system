Handwritten Seaweed Script phrase used as a warm, human accent beside display type. Use sparingly — one phrase per view, lowercase, three to five words.

```jsx
<Kicker tone="hero">A top kicker with</Kicker>
<ScriptAccent>a handwritten accent.</ScriptAccent>
<ScriptAccent size={29} tone="olive" rotate={-3}>{"and another\n for good\n    measure..."}</ScriptAccent>
```

Never set the script face in uppercase and never use it for body copy.
