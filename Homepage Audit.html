Homepage vs. the design system

Audit of the client-approved homepage (frame 01.00, node 2008:2564) against the Toccala Design System, so secondary pages inherit one consistent set of rules.

17 Aug 2026 · source: Toccala — Homepage.fig · 79 variables, 6 component sets, 11 standalone components read

Headline

The system aligns closely, as you expected — all 12 palette colours, the radius scale, the spacing scale and the semantic aliases match the file exactly. Four real discrepancies, all now corrected. The bigger issue is not drift: it is that the chrome every secondary page needs (nav, footer, badge, chip, quote card) is in the homepage but not in the system.

Corrected

The approved homepage was treated as the source of truth.

01
Fixed

Paper was 4 units off, and duplicated

The system had --paper: #FFF9F0 plus a second near-white --raw-cream: #FFFDF8. The file has one: Palette/Paper = #FFFDF8 — and that is what the homepage actually paints on the header, hero, pricing band and sample band. #FFF9F0 appears nowhere in the approved design.

#FFF9F0 was→#FFFDF8 now

--raw-cream now aliases --paper, and --surface-card points at Paper. Updated in the tokens, the wordmark asset, figma/variables.json, the setup plugin, the README and the Brand Canvas template — which was rendering the two whites as two separate swatches.

02
Fixed

Paper texture rendered at double scale

The tile is 440×440 natively and the system repeated it at native size. The homepage repeats it at 220px 220px on both texture bands — half size, so the grain is twice as fine. The system's bands read visibly coarser than the approved page. Now 220px in --texture-tile-size, TexturePanel, the template and the docs.

03
Fixed

Two file colours were undocumented

#D8AB43 — the sketch-ring stroke on the hero, 6 uses, brighter than Palette/Sun — and #ABD1CC (Literal/Mint) existed in the file but not in tokens/colors.css. Both added as literals and registered in the Figma variable payload, so they stop being reinvented by hand.

04
Fixed

Section rhythm existed nowhere

The homepage has a clear vertical system — 96px default band, 112px generous, 64px page gutter, 96px on texture bands, 16px section-head stack — but the system carried only two gutter tokens, so a secondary page had nothing to follow. Added --section-y*, --section-gap*, --section-head-gap, --header-h and --content-max: 1312px, plus a "Section rhythm" card documenting all ten bands and the ground-alternation rule.

Gaps that will bite on secondary pages

Not drift — genuinely missing. These are the pieces every page except the homepage needs, and they only exist as homepage layers today.

05
Missing

Nav and footer are not components

Header: 104px tall, 64px side gutters, wordmark 150×36.685, nav gap 36, md button 173×61. Footer: 426px, padding 64/64/40, gap 64, photo ground, 329px brand column, link columns at 18px gap with 12px between links, 72px between columns. The file also carries Header-Nav-Wireframe-Mobile and 09-Footer-Wireframe-Mobile. Until these are components, every secondary page rebuilds them and they drift apart.

06
Missing

Badge, Chip, Card / Quote, 4-col plan card

  • Badge — pill, Brick ground, Parchment label, 8×16 padding.
  • Chip component — in the file, absent from the system.
  • Card / Quote — the testimonial card, used twice on the homepage.
  • Plan — 4 Col — a plan-card variant the system's PlanCard doesn't cover.

Needs your call

07
Decision

The file has no text styles at all

Its Type collection is five font-family strings — no sizes, no leading. There are zero Figma text styles. So the type ladder lives only in the system's CSS and in the figma/text-styles.json I authored; the delivery file cannot enforce it. Publish those text styles into the Figma library or secondary-page type will drift the moment someone sets a heading by hand.

08
Decision

Two near-identical oranges

The hero accent circle is #D96F4A; Palette/Clay is #D76B45 — two units apart, indistinguishable on screen. This is drift inside the Figma file: the circle isn't bound to the Clay variable. Recommend binding it rather than adding a token. Say the word and I'll leave the system as is.

09
Decision

TextLink is 17px on light, 18px on dark

That 1px difference is in the source and the system copies it faithfully. Almost certainly unintentional. Recommend 18px for both — but it's a visible change to the approved page, so it's yours to call.
