# Typography Sheet (UI kit)

Static recreation of the source file's **Typography System** frame (node `4:899`, 853.802×1869) — all twenty rows at real size, each annotated with the face, size and leading it carries in the file. Rows are stacked with a 56px gap, exactly as in the source.

The face column names the *original* face. `Optima nova LT Pro` is a licensed font and is not shipped here — see the substitution note in `../../readme.md`.
